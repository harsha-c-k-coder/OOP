# 🏗️ Python Object-Oriented Programming (OOP) Examples

This repository contains beginner-friendly Python programs demonstrating the fundamental concepts of **Object-Oriented Programming (OOP)**. Each program focuses on creating classes, objects, constructors, and methods.

## 📌 Programs Included

### 1️⃣ Student Class
- Creates a `Student` class
- Uses a constructor (`__init__`) to initialize student details
- Displays student age and name

### 2️⃣ Car Class
- Creates a `Car` class
- Stores brand and model information
- Displays car details

### 3️⃣ Rectangle Class
- Creates a `Rectangle` class
- Calculates:
  - Area
  - Perimeter
- Demonstrates the use of class methods

### 4️⃣ Employee Class
- Creates an `Employee` class
- Stores employee name and salary
- Displays employee information using a class method
